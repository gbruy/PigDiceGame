# 🎲 Pig Dice Game

Projeto desenvolvido durante estudos em Python e Pygame.  
É um jogo simples para dois jogadores onde cada um rola um dado e tenta acumular pontos até chegar a 50.

## 🛠 Tecnologias usadas
- Python 3.11+
- Pygame
